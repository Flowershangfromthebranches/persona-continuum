结论：证据性消息与日常寒暄在纯文本特征上不可分（question-adjacency + first-person 两个最强确定性规则合计也只覆盖 ~14% FN）。 达到 95% recall 需要选择几乎全部 turns（等价于放弃 sparse），因此 balanced 未通过验收。 后续提升方向：dispatch 内 ±1 neighbor 已天然覆盖相邻证据；真正的缺口在「短句+强语境」消息，需模型级信号（非 reserve）才能区分。

7. 方法论与隐私声明

  • 本轮所有 benchmark 与 ShadowGate 评估均为纯本地离线：agent_calls 为「含 selected target 的窗口数」（与管线计费语义一致），input_tokens 为窗口 token 估算；未调用任何外部 API。
